## Como rodar
Abra o `index.html` no navegador, ou pelo terminal:

    cd pagina-cerberus
    python3 -m http.server 8000

Depois acesse http://localhost:8000

## Trabalho em grupo (Git)
Cada pessoa edita só a sua seção e trabalha na sua branch:

    git checkout -b feature/seu-nome-secao
    git add .
    git commit -m "feat(descricao): ajusta texto - Seu Nome"
    git push origin feature/seu-nome-secao

Depois abra um Pull Request e comente nele.
